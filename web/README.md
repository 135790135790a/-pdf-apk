# 漫画书架 · 网页版（电脑上用）

把 **PDF / 一整个图片文件夹** 变成能翻页的网页漫画书。纯本地运行，不上传、不联网、不装依赖。

## 怎么打开

**双击上一级目录里的 `打开漫画书架.lnk` 快捷方式**（带书本书图标），或用
`web\start.bat`，都会启动服务并自动打开浏览器（默认地址 http://127.0.0.1:8971/）。
关掉那个黑色命令行窗口就等于关掉这个应用。

> 快捷方式可以随便拖到桌面或任务栏，它记的是绝对路径，不影响使用。
> 程序已经在运行时再双击它，只会帮你把浏览器打开，不会开第二份（避免两个进程抢 `library.json`）。

第一次启动会生成一本 20 页的示例漫画，方便你立刻试翻页。不想要了就在书架卡片右上角 `⋮` → 删除。

命令行启动也可以：

```powershell
cd "C:\Users\86139\Desktop\deepseek\漫画书翻译\web"
python server.py
```

## 在手机上用（同一个 Wi-Fi）

1. 双击 `允许手机访问.bat`（只需一次，会弹 UAC 点"是"，放行 8971-8980 端口）
2. 双击 `打开漫画书架.lnk`，命令行窗口里会打印一行 `手机上： http://192.168.x.x:8971/`
3. 手机连同一个 Wi-Fi，用浏览器打开这个地址
4. 手机浏览器菜单 →「添加到主屏幕」，以后一键打开

手机上的手势：

| 操作 | 手势 |
| --- | --- |
| 翻页 | 左右滑动，或点屏幕左/右 1/3（方向随"从右往左"自动对调） |
| 缩放 | **双指捏合**；或在页面中间快速连点两下（1 倍 ↔ 2.2 倍） |
| 平移 | 放大后单指拖动 |
| 工具栏 | 点屏幕中间 |
| 返回书架 | 左上角「← 书架」 |

> 这条路上 PDF 是**电脑**在渲染，所以电脑要开着、手机和电脑要在同一个 Wi-Fi。
> 想彻底脱离电脑，需要装成 APK —— 见上一级 `README.md` 第 10 节。
> 手机访问时"本机路径"导入会被拒绝（那是电脑上的路径），请用「文件夹」或「文件」。

## 三种导入方式

点「＋ 导入漫画」会弹出三个选项：

| 方式 | 适合 | 行为 |
| --- | --- | --- |
| **文件夹** | 漫画按文件夹放好的情况 | 打开文件夹选择器，**整个文件夹 = 一本书** |
| **本机路径** | 文件夹很大（几百张） | 粘贴路径如 `D:\漫画\海贼王\第01卷`，服务端直接读磁盘，不用上传，最快 |
| **文件** | 单个 PDF 或零散图片 | 一个 PDF = 一本书；多选图片 = 一本书 |

也可以**直接把文件或文件夹拖进窗口**（拖文件夹会递归进去）。

### 一个文件夹怎么变成一本书

- **按文件名自然排序**：`1.png` → `2.png` → `10.png`（不是 `1, 10, 2`）
- **子文件夹按名字顺序接在后面**：`第01话/*` 之后是 `第02话/*`，`ch2/` 在 `ch10/` 前面
- **文件夹名 = 书名**（可以之后改名）
- 里面的 **PDF 各自单独成书**（一个 PDF 一本）
- 非图片文件（`说明.txt`、`Thumbs.db`、`.DS_Store` 之类）自动忽略
- 坏掉的图片会跳过并继续导入，不会让整本失败

举例：

```
海贼王 第01卷/          →  书架上出现《海贼王 第01卷》，7 页，顺序就是下面这个顺序
├─ 1.png
├─ 2.png
├─ 10.png
├─ ch2/1.png
├─ ch2/2.png
├─ ch10/1.png
├─ 说明.txt            ← 忽略
└─ 附录.pdf            →  另外单独一本《附录》
```

## 看书

| 操作 | 做法 |
| --- | --- |
| 翻页 | `←` `→`、滚轮、点屏幕左右两侧、鼠标左右拖拽 |
| 跳页 | 底部滑杆 |
| 放大 | 双击页面中间（2.2 倍）/ `Ctrl` + 滚轮 / `+` `-`；放大后拖动平移，点「适应窗口」还原 |
| 工具栏 | 点页面中间切换显示 |
| 阅读方向 | 底部「从右往左 / 从左往右」；日漫选右→左，国漫美漫选左→右 |
| 改名 / 删除 | 书架卡片右上角 `⋮` |
| 返回书架 | `Esc` 或左上角「← 书架」 |
| 全屏 | `F` |

进度会自动记住，回到书架时卡片上会显示"读到 N 页"。

## 数据存在哪

```
web/data/
├─ library.json          # 书名、页数、阅读进度、阅读方向
└─ books/<12位ID>/
   ├─ page_001.jpg       # 第一页同时也是封面
   └─ page_002.jpg …
```

- 想备份：整个 `data` 文件夹拷走即可。
- 想清空：关掉程序后删掉 `web/data`，下次启动会重新生成示例书。
- 页面是 **1600px 宽、JPEG 质量 88**。觉得糊可以把 `server.py` 里的 `TARGET_WIDTH` 调大（2048），
  代价是占空间更大。

## 常见问题

**端口被占用** —— 会自动换一个空闲端口（8972、8973…），看命令行窗口里打印的地址。

**拖文件夹进来没反应** —— Chrome / Edge 支持；如果拖的是"库"里的特殊位置（如"我的电脑"），
可以改用「文件夹」按钮或「本机路径」。

**「本机路径」提示路径不存在** —— 路径要写到具体文件夹，可以带引号直接粘贴；
建议用 `复制文件地址`（Shift + 右键）拿到绝对路径。

**提示"没有找到可用的 Python 3"** —— 装个 Python 3.9+（python.org），安装时勾选
*Add python.exe to PATH*。这台机器上已经有 `Python311`，正常情况不会遇到。

**提示"服务端缺少 PyMuPDF，无法处理 PDF"** —— 图片/文件夹导入仍然可用；
补上 PDF 支持只需 `pip install pymupdf`。

**PDF 有密码** —— 不支持，会提示导入失败。

## 和安卓版的关系

同一套产品思路的两种实现：

- `../app/` 是安卓原生版（Kotlin + Compose + Room），需要 Android Studio 编译。
- `web/` 就是本目录，用 Python 把 PDF 渲染成图片，浏览器里翻页；同样的"书架 / 阅读器 / 从右往左"设计。

网页版先用来验证交互和产品手感，安卓版是最终形态。
